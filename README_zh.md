# 实验资料说明

本仓库包括两部分：**裸基模能否生成合格的 Ascend C 工程，以及固定生成实现进入真实模型后表现如何。**

1. [V3 裸基模评测](01_v3/README.md)：九模型、八算子、三轨迹、五轮，共1080轮。模型不自主使用工具，编译、测试和反馈由外部 Harness 完成。保留逐轮提示、响应、反馈、工程与评价记录。
2. [真实模型替换](02_model_transfer/README.md)：GELU、SwiGLU、ForeachNorm、Sigmoid，覆盖五个宿主检查点和四种任务数据集。固定候选后依次复核基准、检查真实输入、评价任务结果、测量完整路径，再扩展输入条件并解释差异。

先看两部分的 `tables`；需要核对数字时，查看 `evidence` 中的原始记录公开副本。`metadata/member_manifest.jsonl.gz` 建立公开位置与原来源之间的对应，并保留处理前后哈希。可运行 `python tools/find_evidence.py --query 关键词` 搜索原文件名、候选或记录路径。

正式应用口径：33份候选尝试、32份原基准通过、31份应用准入；65组正式任务比较。失败和未测不填零；人工诊断修复不计为原候选成功。

本次不含未完成 Opus 的正式统计。V3 八类算子完整保留。未重新上传模型权重和数据集图片，提供已有划分清单、来源和校验信息。

这是公开资料包，不是已封装为一键运行的跨机器环境。离线核查不需要 NPU；重新执行实验需要恢复相应软硬件环境、模型与数据，并配置路径和服务凭据，见[复现说明](REPRODUCIBILITY.md)。
