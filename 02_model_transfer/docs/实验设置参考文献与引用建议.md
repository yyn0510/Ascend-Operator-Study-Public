## 3. 文献指标与我们的实现如何对应

### AI2D与MMStar

Accuracy是正确答案数除以评估题目总数。我们的文本解析、无效答案处理、子集筛选与提示模板仍须按实际协议说明。MMStar原论文还有多模态增益MG和泄漏ML指标，本项目没有运行它们需要的有图／无图等对照，因此只引用其任务与准确率设置，不声称完成了MG/ML评测。[MMStar §4–5](https://proceedings.neurips.cc/paper_files/paper/2024/file/2f8ee6a3d766b426d2618e555b5aeb39-Paper-Conference.pdf)

本项目MMStar排除了AI2D来源样本后形成固定dev/eval划分。这是我们减少任务重复的设计，不是MMStar原论文规定的官方划分；也不能由此声称已排除宿主预训练数据泄漏。

### DocVQA

原论文明确提供ANLS与完全匹配准确率的双指标依据，因此当前保留ANLS式分数和EM具有直接出处。[DocVQA §5.1](https://arxiv.org/html/2007.00398v2#S5.SS1)

本项目实现先转小写、去首尾空白，保留内部空白；取多个参考答案中最高的归一化Levenshtein相似度，**相似度≥0.5时保留，否则置零**。普通字符串`none`按答案文本处理。需继续称为“ANLS式分数”，并给出这些细节。

指标原始出处ST-VQA的公式使用归一化距离严格小于0.5的条件；在恰好位于边界时，与本项目的包含等号规则存在表述差异。这里引用其指标思想，不宣称逐字复现原公式或官方竞赛评分器；现有实验数据不因引用整理而改动。[ST-VQA §3.4，式(1)](https://arxiv.org/html/1905.13648v2#S3.SS4)

### COCO检索

图→文R@K检查前K条文本中是否包含该图的正确描述；文→图R@K检查正确图片是否进入前K。方向不能互换，也不能把检索Recall@K写成图像分类Top-K准确率。对应依据是Karpathy论文§4.1与BLIP表5。

我们的检索库是固定1000图和5002条文本，不应为了与文献“每图五描述”的常见写法一致而写成5000条。BLIP表5采用5000图COCO测试库，我们的绝对分数不能与其直接排名；本项目比较的是同一宿主、同一检索库中原生与替换的差异。

## 4. 建议放进论文的简洁表述

以下是引用组合与措辞建议，不改变已经执行的实验设置。

**任务选择：** 为覆盖图示理解、多模态选择题、文档问答和图文匹配，我们分别采用AI2D、MMStar、DocVQA与COCO的固定子集。AI2D、MMStar和DocVQA也出现在Qwen2.5-VL的评测中；COCO双向检索则用于BLIP等视觉语言研究。本文在这些任务上配对比较原生宿主与算子替换后的表现。〔`kembhavi2016diagram; chen2024mmstar; mathew2021docvqa; lin2014coco; bai2025qwen25vl; li2022blip`〕

**评价指标：** AI2D和MMStar使用选项准确率；DocVQA参照原任务的编辑距离相似度与严格匹配双指标设置，报告本文明确定义的ANLS式分数和EM；COCO采用图→文及文→图的R@1、R@5、R@10。所有结果用于固定子集上的配对比较，不作为官方完整榜单成绩。〔`kembhavi2016diagram; chen2024mmstar; mathew2021docvqa; karpathy2015alignments; li2022blip`〕

**宿主选择：** 采用Qwen2.5-VL-3B/7B和InternVL2-4B作为生成式宿主，并以OpenAI与LAION的CLIP ViT-B/32检查点覆盖双编码器检索路径。该选择用于观察不同规模、模型结构与调用方式下的替换表现，不以参数量单独解释差异。〔`bai2025qwen25vl; opengvlab2024internvl2; opengvlabInternvl2Model; radford2021clip; laionClipB32`〕

## 5. 哪些内容应由本项目证据支撑

| 内容                          | 应如何处理                                 |
| --------------------------- | ------------------------------------- |
| 某份候选无质量损失、发生加速或执行失败         | 引本项目数据表和日志；外部模型论文不能证明这些结论             |
| token／选项变化、Top1结果变化、错→对与对→错 | 作为本项目的行为诊断指标，明确计算方法；不必硬称为数据集官方指标      |
| 原生、包装、候选三条路径计时              | 是本项目为分辨适配成本设置的对照；上述模型／数据集论文并不直接规定这套协议 |
| 三个独立计时时段、数值阈值、输入扫描范围        | 是本项目冻结的实验设计，不能由“知名论文也用这个模型”推出其充分性     |
| ForeachNorm单点修改后通过          | 用受控实验支持局部机制解释，不作为原始生成候选成功，也不靠引用推成普遍规律 |
