# Ascend C Operator Generation and Model Transfer: Research Artifact

This artifact contains two connected experiments: evaluating complete Ascend C operator projects generated by foundation models, and evaluating selected generated implementations inside real multimodal models. It is a data-and-code release, not a claim of optimal deployment performance.

| Part | Scope | Start here |
|---|---|---|
| V3 generation evaluation | 9 models × 8 operators × 3 trajectories × 5 rounds = 1,080 rounds | [V3 guide](01_v3/README.md) |
| Model transfer | GELU, SwiGLU, ForeachNorm and Sigmoid; five host checkpoints; AI2D, MMStar, DocVQA and COCO retrieval | [Transfer guide](02_model_transfer/README.md) |

The foundation models do not autonomously use tools, skills or agents. An external harness submits projects for evaluation and returns feedback. Model transfer reuses fixed V3 implementations rather than generating new kernels.

The transfer pipeline is: **freeze candidates → recheck the original benchmark → test real inputs → compare task outputs → measure the complete execution path → investigate input conditions and observed differences**. Failure records and manually modified diagnostic implementations remain distinct from successful original candidates.

## Reading and verification

- Start with the `tables/` folders; these contain consolidated results rather than a chronology of execution batches.
- `evidence/` contains independently extractable ZIP archives of recorded evidence. ZIP names retain execution identifiers for traceability, not independent-sample counting.
- `code/`, `protocols/`, `candidates/` and `data/` contain execution snapshots, frozen settings, source projects and subset manifests. Large weights and dataset images are not redistributed.
- [Reproduction guide](REPRODUCIBILITY.md) distinguishes offline verification from NPU reruns.
- [Release scope and transformations](RELEASE_NOTES.md) explains exclusions and sanitization.
- [Third-party notices](THIRD_PARTY_NOTICES.md) and [resource entry points](RESOURCES.md) describe external dependencies.

Python 3, standard library only:

```bash
python tools/verify_artifact.py
python tools/find_evidence.py --query ForeachNorm
```

Download the repository before running the commands. Do not upload only this README or only the outer delivery ZIP.

## Scope boundaries

The incomplete Opus run is excluded from the formal V3 cohort. All eight original V3 operator tasks are included.

Task accuracy, output identity, numerical admission and speed are different outcomes. Timing uses controlled inputs and must not be interpreted as average latency across the task dataset. Selected-candidate admission rates are not population estimates for all generated implementations.

Historical logs and code snapshots document the experiments as executed. Old timestamps, local runtime locations and contemporaneous status descriptions inside evidence are not current instructions. Read the consolidated tables and current guides for final status.
